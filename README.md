# QuizRush 🎮

یک سایت کوییز آنلاین زنده (مثل کاهوت) برای بازی هم‌زمان با دوستان.
این پروژه مخصوص یک موضوع خاص نیست — هر «موضوع» (Topic) یک بسته‌ی جداست
که هرکدوم ۳۰ سوال (۱۰ آسون / ۱۰ متوسط / ۱۰ سخت) داره. فعلاً فقط بسته‌ی
«دنیای مارول» ساخته شده، ولی می‌تونی هر وقت خواستی موضوعات جدید
(مثل هری‌پاتر، فوتبال، تاریخ ایران و ...) به همین سایت اضافه کنی.

## راه‌اندازی

۱. یک پروژه در https://supabase.com بساز (رایگان).
۲. برو به SQL Editor پروژه‌ات و کل محتوای فایل `schema.sql` رو اجرا کن.
۳. برو به Project Settings → API و دو مقدار زیر رو کپی کن:
   - Project URL
   - anon / publishable key
۴. فایل `index.html` رو باز کن و این دو خط رو در بالای تگ `<script>` پیدا کن و مقادیر خودت رو جایگزین کن:
   ```js
   const SUPABASE_URL = "...";
   const SUPABASE_ANON_KEY = "...";
   ```
۵. فایل رو در یک ریپازیتوری GitHub آپلود کن و GitHub Pages رو روشن کن.

## قفل بودن Host

فقط کسی که یک GitHub Token معتبر مال اکانت `Parsapoxo` وارد کنه می‌تونه اتاق بسازه؛
بقیه فقط می‌تونن با کد اتاق وارد بشن. این با تماس مستقیم مرورگر به GitHub API
(بدون هیچ سروری) چک می‌شه، پس توکن واقعی هیچ‌وقت داخل کد سایت ذخیره نمی‌شه.
توکن رو بدون هیچ scope اضافه‌ای بساز (GitHub → Settings → Developer settings →
Personal access tokens)، چون فقط برای شناسایی هویت لازمه.

## عکس‌های پروفایل (Avatars)

یک پوشه به اسم `avatars` توی ریشه‌ی همین ریپو بساز و هر عکسی که خواستی
(png/jpg/webp/gif) رو باهاش آپلود کن — هر اسمی، فقط بدون فاصله و حروف فارسی
(مثلاً `1.png`, `ali.jpg`). سایت خودش لیست عکس‌های داخل این پوشه رو زنده از
GitHub می‌خونه و به‌عنوان گزینه‌ی انتخاب پروفایل نشون می‌ده — نیازی به تغییر کد نیست.
انتخاب آواتار برای همه اجباریه.

## پوستر موضوعات (Posters)

یک پوشه به اسم `posters` توی ریشه‌ی همین ریپو بساز. برخلاف آواتارها، اینجا اسم فایل
باید دقیقاً برابر شناسه‌ی (id) همون موضوع داخل `TOPICS` باشه، به‌علاوه‌ی پسوند `.png`:

- مارول → `posters/marvel.png`
- دیزنی → `posters/disney.png`
- دریم‌ورکس → `posters/dreamworks.png`

اگه پوستر یک موضوع رو آپلود نکنی، اون باکس فقط بدون عکس (با اسم موضوع) نمایش داده
می‌شه و سایت خراب نمی‌شه.

## زبان سایت (فارسی / English)

یک دکمه‌ی تغییر زبان بالای گوشه‌ی چپ صفحه هست که کل رابط کاربری (متن دکمه‌ها،
عنوان‌ها، پیام‌ها) رو بین فارسی و انگلیسی عوض می‌کنه. **سوالات کوییز همیشه فارسی
باقی می‌مونن** و ترجمه نمی‌شن. انتخاب زبان توی مرورگر هرکس ذخیره می‌شه.

## ظرفیت بازی

هر اتاق حداکثر ۶ بازیکن می‌تونه داشته باشه.

## نکته‌ی امنیتی

جدول‌های این پروژه با دسترسی عمومی (anon) باز هستن چون این یک بازی خصوصی و بدون اطلاعات حساسه.
از این پروژه‌ی Supabase برای چیز دیگه‌ای که داده‌ی مهم داره استفاده نکن.

## افزودن موضوع جدید

داخل `index.html` به آبجکت `TOPICS` یک کلید جدید با همون ساختار اضافه کن:
- `name`: اسم فارسی موضوع
- `nameEn`: اسم انگلیسی موضوع (برای حالت زبان انگلیسی)
- `questions`: آرایه‌ی ۳۰ سوالی (۱۰ آسون، ۱۰ متوسط، ۱۰ سخت)، که این‌ها همیشه فارسی می‌مونن

به‌محض اضافه‌شدن، اون موضوع خودکار توی لابی (با یا بدون پوستر) ظاهر می‌شه. یادت
نره پوستری هم به اسم همون شناسه (id) توی پوشه‌ی `posters` اضافه کنی.

## نسخه‌بندی

هر آپدیت شماره‌ی نسخه (گوشه‌ی پایین‌راست سایت) رو طبق قوانین semantic versioning بالا می‌بره:
- **MAJOR** (x.0.0): تغییرات بزرگ/ساختاری
- **MINOR** (x.y.0): قابلیت جدید
- **PATCH** (x.y.z): رفع باگ یا تغییر جزئی
